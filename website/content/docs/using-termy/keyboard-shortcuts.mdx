---
title: Keyboard shortcuts
description: Browse and run every shortcut from one popup.
---

Click the Termarx logo at the left of the title bar to open the shortcuts popup.
The logo is shown on Windows and macOS while `show_termy_in_titlebar = true`.

- Each row has the action on the left and its current key binding on the right.
- Bindings are read from your configuration, so custom `keybind` lines are
  reflected. Actions without a binding are not listed.
- Click a row to run the action, the same as pressing the keys.
- Press `Esc` or click outside the popup to close it.

The popup follows the interface [language](/docs/customize/appearance#language).
For the full list of defaults see
[Keybinding defaults](/docs/reference/keybinding-defaults); to change them see
[Keybindings](/docs/customize/keybindings).
